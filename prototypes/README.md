# Прототипы редизайна лендинга

Поисковые макеты, сделанные при подборе нового визуального языка для лендинга.
**Это не продакшен.** Боевая страница — `docs/index.html`, и она этими файлами не
затрагивается: каталог лежит вне `docs/`, поэтому GitHub Pages его не публикует.

Каждый файл самодостаточен: один HTML, шрифты с Google Fonts, Three.js с CDN там,
где он нужен. Ни сборки, ни зависимостей.

## Как посмотреть

```bash
cd prototypes && python3 -m http.server 8766
# затем открыть http://127.0.0.1:8766/f1-hybrid.html
```

Через `file://` работать не будет: часть прототипов использует ES-модули, которым
нужен http-протокол.

## Что удалось выяснить

- **Читаемость и эффектность не обязаны конкурировать.** `f1-hybrid` держит весь
  контент в HTML (краулеры и рекрутёры получают обычную страницу), а терминал
  добавляется поверх как отдельный слой. Удали из него весь скрипт — останется
  корректный документ.
- **Консоль вызывается тильдой**, и обработчик слушает также `ё`: на кириллической
  раскладке это та же клавиша, без второго символа фича молча ломается.
- **Затемняющая подложка не делается тенью скрытого элемента.** `transform` уводит
  панель за экран, но её `box-shadow` со спредом продолжает накрывать страницу.
  Нужен отдельный слой с `opacity` и `visibility`.
- **Побуквенные `span` ломают перенос строк** — слова нужно оборачивать в
  `display:inline-block; white-space:nowrap`, иначе строка рвётся посреди слова.
- **Терминал, печатающий ввод обратно, — это XSS-поверхность.** Вывод строится
  через `innerHTML`, поэтому всё пришедшее от посетителя проходит через `esc()`, а
  deep-link `?console=<cmd>` выполняет только команды из белого списка. Проверять
  принадлежность нужно через `hasOwnProperty`, а не `in`: `in` находит и
  `constructor` с `toString` из прототипа Object.
- **Три.js в headless Chrome без GPU не рисует.** Для скриншотов нужны
  `--enable-unsafe-swiftshader --use-angle=swiftshader`, иначе рабочая сцена
  выглядит сломанной.
- **`--virtual-time-budget` проматывает таймеры JS, но не CSS-переходы.** Снимок
  ловит страницу в начале анимации `opacity`, и живая страница выглядит пустой.

## Если возвращаться к теме

Кандидат — `f1-hybrid.html`. Чего в нём ещё нет для боевого применения:
двуязычности RU/EN, светлой темы, разделов навыков, образования и проектов,
и печатного режима, из которого оформление убирается, — PDF должен оставаться
строгим.
